# Test reports

Store one report per substantial test run in this folder, named `YYYY-MM-DD-<task-or-commit>.md`. Record commit/build identifier, environment, commands actually executed, passed/failed/skipped counts, APK or artifact paths, runtime logs/screenshots, and known gaps. Never mark unexecuted tests as passed. See `2026-11-10-phase-01-local.md` for the latest local Phase 01 checks; native/emulator and remote CI verification remain pending.
